🏗️ ARCHITECTURE
================================================================================

Frontend:
---------
MoonEngineTemplate.tsx
  └─ Contributors Section
      ├─ Visual list of contributors
      ├─ "Add from Authority" button
      └─ AuthoritySearchDialog component
          └─ authorityHub.searchAll(query)
              ├─ LOC NAF API
              ├─ VIAF API
              ├─ Wikidata SPARQL
              └─ AfIqa API

Backend:
--------
POST /make-server-49c0e13c/save-record
  └─ Validates access token
      └─ await kv.set(`record:${id}`, record)
          └─ Supabase PostgreSQL
              └─ Persists forever ♾️

Data Flow:
----------
User clicks "Add from Authority"
  → AuthoritySearchDialog opens
    → User searches for "Shakespeare"
      → System queries 4 sources in parallel
        → User selects result
          → UnifiedPerson created with LOC URI
            → handleAuthoritySelect adds bf:Contribution
              → Contributor appears in list
                → User clicks "Save Record"
                  → POST to backend with auth token
                    → Saved to Supabase KV store
                      → Success toast shown
                        → Record persists forever ✅
