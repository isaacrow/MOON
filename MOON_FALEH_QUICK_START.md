# 🚀 Moon Faleh - Quick Start Guide

## 🎯 Get Started in 3 Minutes

### Step 1: Launch Moon Faleh (10 seconds)
1. Open your MOON application
2. Look for the **purple/pink/red gradient card** on the Dashboard
3. Click **🌙 MOON FALEH**

### Step 2: Load an Example (30 seconds)
1. Click **"Load Real Example"** button (top toolbar)
2. Select **"The Great Gatsby"** from the dropdown
3. Observe the complete BIBFRAME record with:
   - Work title: "The Great Gatsby"
   - Contributor: F. Scott Fitzgerald (with LOC URI)
   - Subjects: American fiction, Jazz Age
   - Publication: Scribner, New York, 1925
   - All proper authority links ✅

### Step 3: Explore the Interface (2 minutes)

#### Try the Wizard Steps:
- Click **"1. Work"** - See intellectual content
- Click **"2. Instance"** - See physical details
- Click **"3. Publication"** - See provenance
- Click **"4. Item"** - See holdings

#### Try Different Previews:
- **Form** - Cataloging interface
- **Graph** - Authority connections
- **Validation** - Quality check
- **MARC** - Traditional format
- **RDF** - Turtle syntax
- **JSON** - JSON-LD structure
- **OPAC** - Public view
- **Mind Map** - Visual relationships

### Step 4: Try Authority Search (1 minute)
1. Click any authority tab (e.g., **"NAF Names"**)
2. Type: **"Shakespeare"**
3. Click **Search**
4. Select **"Shakespeare, William, 1564-1616"**
5. Click **"Use This Authority"**
6. See it added with proper LOC URI! ✅

### Step 5: Save Your Work (30 seconds)
1. Make any change to the record
2. Click **Save Record** (top toolbar)
3. Watch status change: Unsaved → Saving → Saved ✅

## ✅ You're Ready!

You've just:
- ✅ Loaded a real LOC record
- ✅ Explored all preview modes
- ✅ Used authority search
- ✅ Saved to the database

## 🎓 Next Steps

### Create Your First Record from Scratch:

#### For a Book:
1. **Step 1: Work**
   - Title: "Your Book Title"
   - Click **"NAF Names"** → Search for author → Select
   - Add subjects by clicking **"Subjects"** tab

2. **Step 2: Instance**
   - Enter ISBN: `978-0-123456-78-9`
   - Click **"Auto-fill from ISBN"** (magic! ✨)
   - Add page count in "Extent"

3. **Step 3: Publication**
   - Click **"Publishers"** → Search → Select
   - Choose publication place
   - Enter year

4. **Step 4: Item** (Optional)
   - Add shelf mark
   - Add barcode

5. **Save!** 💾

### Advanced Tricks:

#### Multi-Author Books:
- In Step 1, click **"+ Add Contributor"**
- Search for each author
- Select their role (Author/Editor/Translator)

#### Books with Subjects:
- Click **"Subjects"** tab in toolbar
- Search Library of Congress Subject Headings
- Add multiple subjects

#### Translations/Editions:
- Check ✅ **"Enable Expression Layer"**
- Creates Work → Expression → Instance → Item
- Perfect for different language editions

#### Import Data:
- Click **"Import"** button
- Upload JSON-LD or Turtle file
- System parses and loads data

## 🔥 Pro Tips

### Tip 1: Start with Examples
Don't start from scratch! Load a similar example and modify it. Much faster!

### Tip 2: Authority Search Everything
Never type names manually. Always search authorities first. Proper URIs = better data.

### Tip 3: Use ISBN Auto-Fill
For modern books, ISBN lookup saves 80% of typing. Let the system do the work!

### Tip 4: Validate as You Go
Check the **Validation** tab after each step. Fix errors early.

### Tip 5: Save Often
Click Save after completing each step. Browser crashes happen!

## ❓ Common Questions

### Q: What if I can't find an authority?
**A:** Use the custom entry option. Type manually and the system creates a local URI.

### Q: Do I need all four steps?
**A:** Work, Instance, and Publication are required. Item is optional (for holdings).

### Q: Can I edit a saved record?
**A:** Yes! The system updates existing records when you save again.

### Q: What's the Expression layer for?
**A:** Use it for translations, editions, or adaptations. Adds FRBR Expression level.

### Q: How do I add multiple authors?
**A:** Click "Add Contributor" in Step 1. Search and add as many as needed.

### Q: Can I import MARC records?
**A:** Not yet, but MARC import is planned. For now, export from Moon Faleh is supported.

### Q: What if validation fails?
**A:** Click the **Validation** tab to see specific errors. Fix highlighted fields.

### Q: Can I work offline?
**A:** No, authority search and save require internet. But you can export and work locally.
