Dynamic Field Binding Principles

  • Zero Hardcoded Schemas: UI input components are assembled on the fly based on loaded RDF ontology definitions and SHACL constraints.
  • Strict Domain & Range Enforcement: Validates that properties only bind to legal entities (e.g. preventing bf:isbn on Work).
  • URI vs. Literal Segregation: Automatically determines whether an input requires an authoritative URI lookup badge or a structured literal.
  • Round-Trip Graph Stability: Graph parsing into UI forms and re-export back into JSON-LD produces identical canonical triples.

AI Orchestration

Multi-AI Orchestrator: 5-Phase Cataloging Pipeline

Phase 1: Ingestion & OCR Processing
Accepts raw title page OCR, scanned PDFs, MARC XML, or ISBN search input.
Phase 2: Entity & Metadata Extraction
Dissects primary creators, uniform titles, edition statements, and publisher nodes.
Phase 3: Authority Disambiguation
Resolves person/place names against LCNAF, VIAF, and AFIQA to bind persistent URIs.
Phase 4: Subject & Classification Suggestion
Predicts LCSH topical headings, DDC numbers, and auto-generates LC Cutters.
Phase 5: Graph Synthesis & SHACL Validation
Constructs validated W3C JSON-LD graphs ready for storage and export.

Conversion & Formats

Bidirectional Crosswalks & Export Engines

🔄 Bibframe2Marc Engine

Transforms nested BIBFRAME RDF graphs into standard MARC21 records: Leader, 008, 100/700 personal names, 245 title statements, 264 publication info, 300 physical descriptions, 336/337/338 RDA types, and 650/651/655 subjects.

🔁 Marc2Bibframe Engine

Ingests legacy MARC21 and MARC XML files, decomposes them into bf:Work and bf:Instance entities, extracts authority strings into dereferenceable URIs, and produces valid JSON-LD and Turtle.

🏷️ LC Cutter & Classification Engine

Automates Library of Congress Classification (LCC) and Dewey Decimal (DDC) call numbers, calculating algorithmic LC Cutter numbers based on main creator entries and title work marks.

📊 6 Real-Time Live Preview Views

Simultaneous real-time output tabs: 1. W3C JSON-LD (Graph mode), 2. RDF/Turtle (.ttl), 3. MARC21 Tagged View, 4. Patron OPAC Web View, 5. D3 Interactive Mind Map, 6. XML/SPARQL Query Terminal.

Enterprise Persistence Highlights

  • KV Store to SQL Migration: Upgraded from flat key-value pairs to an ACID-compliant normalized relational schema.
  • High-Speed SPARQL-in-SQL: Dedicated indexes on subject, predicate, and object columns allow complex graph queries to execute in sub-millisecond SQL queries.
  • Row-Level Security (RLS): Ensures consortium members and institutional users only access their authorized catalog workspaces.
