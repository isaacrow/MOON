## 📚 What is Classic Theme?

**Traditional Library Edition** - Inspired by vintage library card catalogs and academic institutions.

### **Visual Features:**
- 📜 **Parchment background** with paper texture
- 🟫 **Brown borders** (solid 3px)
- 🏆 **Gold buttons** (shiny, raised 3D)
- 🍷 **Burgundy accents** for headings
- 📖 **Serif fonts** (Georgia, Times New Roman)
- 🎨 **Decorative corners** on panels
- 🪵 **Leather navbar** with gold trim
- 📇 **Catalog card style** for content

### **Colors:**
- Parchment: `#f4f1e8`
- Cream: `#faf8f3`
- Brown: `#8b6f47`
- Burgundy: `#7c2f3e`
- Gold: `#d4af37`
- Leather: `#654321`

---

## 🎯 How to Use Classic Theme

### **Quick Steps:**

1. **Open Moon Engine** from dashboard

2. **Click "Theme" button** (top-right corner)

3. **Select "📚 Classic"** from dropdown:
   ```
   ✨ Glass
   ⚡ Neon
   📚 Classic ← Click this!
   ```

4. **Done!** Interface changes to classic library style
